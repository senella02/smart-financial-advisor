# LLMFA report diagram review

Reviewed on 21 November 2026. Which figures from the previous LLMFA report can help explain Smart Financial Advisor, and which views are still missing? The comparison uses three criteria: fit with the current requirements, coverage in existing diagrams, and whether a figure answers a distinct reader question. Figure and page numbers refer to the 55-page [LLMFA final report recorded as source S3](../source-notes.md#s3-previous-llmfa-final-report).

The [Phase 1 architecture](../phase-1-planning/architecture.md) uses Vercel Schedules, Queues and Functions with PostgreSQL full-text retrieval. The [proposed Phase 2 design](../final/final-architecture.md#delivery-phases) uses Airflow for background work and Pinecone for public passage retrieval after bilingual evaluation. Any report figure should identify which phase it depicts and whether it describes a design or the implemented system.

For a short Phase 1 report, the existing architecture overview, a cited-chat sequence and a pilot ingestion flow cover the main design. The publication lifecycle and privacy boundaries add the most new information. The evidence model is useful if the report needs to explain why a citation can be traced back to a specific filing version.
