# Docling extraction on SEC filings

Research report · 21 November 2026

Can Docling preserve an EDGAR table's labels, periods, units, and values, and can the extracted evidence be traced to its original location? The check compared Docling's structured JSON with the original EDGAR files. It distinguished a document identifier from a location within the document. [FR-12 filing ingestion](../final/functional-requirements.md#fr-12-financial-data-and-news) · [FR-19 grounded answers and citations](../final/functional-requirements.md#fr-19-grounded-answers-and-citations)

## Method

Ran Docling 2.151.1 and docling-core 2.108.0 on macOS with Python 3.12. Saved the original SEC response bytes and converted the local files. Checked the proxy's embedded text with pypdf and a cell's coordinates with PDFium, the HTML DOM with lxml, and workbook sheets, merges, and cells with openpyxl. Used Docling's standard PDF layout and table models with OCR disabled for the text-layer proxy. Checked physical PDF pages 54 and 62–67. For Inline XBRL, tested defaults first, then provided the issuer's extension taxonomy from the EDGAR XBRL ZIP and enabled remote lookup for standard taxonomy files. [Docling formats](https://docling-project.github.io/docling/usage/supported_formats/) · [XBRL options](https://docling-project.github.io/docling/usage/advanced_options/)

None of the local-file conversions carried the original EDGAR URL in its output. The fetch step already knows the URL and accession, so those are available independently of the parser. Format-specific locators differ in what they establish. A PDF page and bounding box identify a visual region. A workbook sheet and cell identify the exact original cell when the offsets are verified. An internal HTML JSON reference identifies only an extracted object.

The spot checks cover Apple filings. They establish specific successes and failure modes across the formats, with no corpus-wide accuracy estimate. Scanned PDFs, legacy XLS, workbook tables starting away from A1, and Vercel deployment fit were outside this run.
