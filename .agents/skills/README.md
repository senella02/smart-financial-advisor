# Project Skills

Place a project-specific reusable workflow in `<skill-name>/SKILL.md` with `name` and `description` frontmatter. Keep its supporting scripts/references inside that skill folder. There are no custom project skills yet.

Use the repository [AGENTS.md](../../AGENTS.md) for standing instructions and [ADRs](../../docs/adr/README.md) for decisions. Do not duplicate them as skills.

See the official [skill authoring and discovery documentation](https://learn.chatgpt.com/docs/build-skills).
